# AGENTS.md

Las reglas y tareas de los agentes viven en las notas de WitherShot, no aquí.

1. Lee `WitherShot-data/notas/agentes-reglas-de-esponja-espreg.md` (reglas, zonas, flujo).
2. Lee tu nota: `agente-wither-esponja-espwit.md`, `agente-grok-composer-esponja-espcom.md` o `agente-gemini-esponja-espgem.md`.
3. Haz las tareas `- [ ]`, márcalas `- [x]` y anota qué archivos cambiaste.
